# Classification datasets

Generated by ClassificationModel.ipynb from diamonds.csv.
cleaned/dataset.csv contains cleaned observations and clarity targets; engineered/dataset.csv adds all features.
experiments/experiment_N/dataset.csv contains each experiment's original-unit features, targets, and split labels.
Each experiment's processed/ folder contains train.csv, valid.csv, and test.csv: exact scaled/encoded inputs with targets.
Each dataset group has a statistics/ folder for its summary CSVs. manifest.json lists every relative path.
Source_Row is the zero-based original CSV data-row position, retained across all exports.
Source_Row, Split, Clarity_Target, and Clarity_Family are metadata/labels, never model inputs.
Statistics files describe each complete exported frame; test statistics are descriptive only.
Preprocessors were fitted on training data only. Rerunning export replaces these generated files.
