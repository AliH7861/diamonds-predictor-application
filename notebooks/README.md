# Notebooks

Run notebooks in order when reviewing the project: `01_old_eda.ipynb` preserves
the main historical analysis, `02_classification.ipynb` predicts clarity family,
and `03_regression.ipynb` predicts price. Reusable implementation belongs in
`src/`; scratch notebooks belong in `sideEDA/`. Generated models, datasets, and
reports belong in their respective top-level folders rather than here.
