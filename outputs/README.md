# Generated outputs

Notebook and script results are separated by workflow:

- `eda/` contains exploratory figures, tables, and reports.
- `classification/` contains clarity-classification figures, metrics, and reports.
- `regression/` contains price-regression figures, metrics, and reports.
- `clustering/` contains K comparisons, buyer profiles, labeled rows, and figures.

These files can be regenerated. Do not place source datasets, notebooks, or model
artifacts here. Historical evidence remains under `sideEDA/`.
