# Recommendation Policy

## Evidence order

For a buying request, filter real dataset rows using the stated budget, carat range, cut, color, and clarity preferences. Rank close matches before explaining trade-offs. Use model estimates only as supporting evidence and use retrieved knowledge for explanations.

## Missing preferences

One concrete constraint such as budget, size, cut, color, or clarity is enough to begin a search. Ask a follow-up only when the request contains no usable search constraint or when the user explicitly names a priority but leaves its acceptable range unclear.

## Communication

Describe recommendations in natural language. State the observed price, carat, cut, color, and five-family clarity. Explain compromises without inventing unavailable certification, origin, customer, or current-market facts.
